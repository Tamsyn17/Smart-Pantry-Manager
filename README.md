# Smart Pantry Manager

Smart Pantry Manager is an Android mobile application developed in Java to help users manage pantry ingredients and receive recipe suggestions based on the ingredients they currently have available.

The application allows users to add, view, edit and delete pantry ingredients, track expiry dates, search their pantry, configure expiry warning settings and view recipes that can be made using sufficient available ingredients.

## Project Information

## Main Features

### Pantry Management

Users can manage the ingredients stored in their pantry.

The application supports full CRUD functionality:

- Create new pantry ingredients
- Read and display stored ingredients
- Update existing ingredients
- Delete ingredients
- Store ingredient name, quantity, unit and expiry date
- Search for ingredients by name

Pantry information is stored locally using SQLite so that the data remains available after the application is closed and reopened.

### Expiry Date Tracking

Each pantry ingredient can have an expiry date.

The application displays an expiry status to help users identify whether an ingredient is:

- Fresh
- Expiring soon
- Expired

Users can configure the number of days used for the expiry warning through the Settings screen.

### Suggested Recipes

The application contains a collection of 20 preloaded recipes.

Recipe suggestions are generated by comparing the ingredients required by each recipe with the ingredients currently stored in the user's pantry.

A recipe is only suggested when the pantry contains all required ingredients in sufficient quantities.

If no recipes can currently be made, the application displays an empty-state message encouraging the user to add more ingredients.

### Strict Ingredient Matching

The recipe matching system checks:

- Ingredient names
- Required quantities
- Measurement units
- Compatible unit conversions

The matching logic also handles common variations such as singular and plural ingredient names.

Supported unit matching includes:

- Grams and kilograms
- Millilitres and litres
- Pieces
- Slices
- Cups

For example, kilograms can be converted to grams and litres can be converted to millilitres when quantities are compared.

### Recipe Details

Users can select a suggested recipe to open its Recipe Detail screen.

The screen displays:

- Recipe name
- Required ingredients
- Required quantities and units
- Cooking instructions

### Settings

The Settings screen allows users to configure the number of days before an expiry date that an ingredient should be considered as expiring soon.

The setting is stored using Android SharedPreferences and remains available when the application is reopened.

### Navigation

The application includes navigation between the main sections:

- Pantry
- Suggested Recipes
- Settings

A menu and bottom navigation options allow users to move between the main areas of the application.

### Welcome Screen

The application opens with a custom welcome screen before entering the main pantry.

The interface uses a clean, modern pastel-purple design throughout the application.

## Database

Smart Pantry Manager uses SQLite for local persistent storage.

The database stores:

- Pantry ingredients
- Recipes
- Recipe ingredients

SQLite was selected because it provides lightweight local database storage suitable for an Android application and does not require an external database server.

The application seeds the recipe database with 20 recipes so that recipe suggestions are available without requiring the user to create recipes manually.

## Validation

Input validation is included to prevent invalid information from being stored.

Examples include:

- Ingredient name cannot be empty
- Quantity must contain a valid value
- Quantity must be greater than zero
- Unit cannot be empty
- Expiry dates must use a valid date format
- Invalid dates are rejected
- Expiry warning days cannot be negative

## How to Run the Application

1. Clone or download this repository.
2. Open Android Studio.
3. Select **Open** and choose the Smart Pantry Manager project folder.
4. Allow Gradle to finish syncing.
5. Select an Android emulator or connected Android device.
6. Run the application using the **Run** button in Android Studio.
7. The Welcome screen will appear first.
8. Select **Enter My Pantry** to begin using the application.

No external database server is required because the application uses a local SQLite database.

## Example Application Flow

A typical user can:

1. Open Smart Pantry Manager.
2. Enter the pantry from the Welcome screen.
3. Add ingredients with quantities, units and expiry dates.
4. View the saved ingredients in the Pantry list.
5. Search for a particular ingredient.
6. Edit or delete existing pantry items.
7. Open Suggested Recipes.
8. View recipes that can be made with the available pantry ingredients.
9. Select a recipe to view its ingredients and instructions.
10. Open Settings to configure the expiry warning period.
